# Projects Showcase

This branch emphasizes the portfolio projects section of the repository.

## Featured CLI Projects

- Calculator: arithmetic operations with input parsing
- Student Management: in-memory record handling
- Tic Tac Toe: two-player game loop and board rendering
- Contact Book: add/search/list workflow
- File Organizer: file copy and command-line arguments
- DSA Toolkit: starter algorithms and data-structure practice

## Suggested Demo Flow

1. Build one project with its local makefile
2. Run the calculator using the sample input under `tests/samples/`
3. Open each project README to compare scope and behavior

## Recruiter Value

This branch makes it easy to review implementation variety, code organization, and how the same C fundamentals are applied in practical tools.
