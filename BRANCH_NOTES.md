# Basics Branch Notes

This branch highlights the foundation of the repository:

- `src/01_basics/` for syntax, types, operators, and input/output
- `src/02_control_flow/` for conditions, loops, and decision making
- `src/03_functions/` for reusable logic and recursion
- `src/04_arrays_strings/` for array traversal and string handling

Suggested review order:

1. Start with `hello_world.c` and `data_types.c`
2. Move to `if_else_demo.c`, `switch_menu_demo.c`, and loop examples
3. Review function examples before practicing arrays and strings

This branch is intentionally focused on the learning base so recruiters can quickly see the progression from syntax to simple program structure.
