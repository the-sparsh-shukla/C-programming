# Portfolio Roadmap

This branch focuses on the documentation and presentation side of the repository.

## Documentation Focus

- Repository overview and build instructions
- Learning path from basics to advanced C
- Topic-level README files and exercises
- Project-level notes for each CLI tool

## Suggested Improvement Path

1. Keep topic READMEs aligned with new examples
2. Add usage examples when a project grows new features
3. Expand tests and sample inputs for more project coverage
4. Record new milestones in this roadmap as the repository evolves

## Why This Branch Exists

It gives recruiters a quick route to the structure, goals, and evolution of the portfolio without needing to read source files first.
